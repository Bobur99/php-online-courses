# Claude Code Project Instructions

The project-wide engineering rules are defined in `AGENTS.md`.

Follow `AGENTS.md` as the primary source of project development rules.

In particular:

- Follow the technical specification (ТЗ).
- Work step-by-step.
- Inspect existing code before creating new abstractions.
- Explain significant technical and architectural decisions before implementation.
- Use TDD for business functionality: test first, verify expected failure, implement, verify success, then refactor.
- Do not add functionality outside the ТЗ without explicit approval.
- Do not perform unrelated refactoring.
- Keep the implementation consistent with the existing architecture and coding style.
